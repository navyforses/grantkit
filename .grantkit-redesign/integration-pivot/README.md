## TL;DR (სრულად — `00-MASTER-PLAN.md` §0)

- **განმარტება:** ინტეგრაციის მხარდაჭერა GrantKit-ისთვის = ახალჩამოსულის **ძიების, ორიენტაციისა და ნდობის ხარჯის შემცირება** — მის ენაზე, მისი სტატუსისა და ეტაპის მიხედვით ვუთხრათ *ვინ* დაეხმარება, *სად*, *რა პირობით*, *რა საბუთით*, *როგორ მიაღწიოს*. არა თავად დახმარების გაწევა.
- **პოზიციონირება:** „ინტეგრაციის ნავიგატორი ქართველი და რუსულენოვანი ემიგრანტებისთვის" — ენა-first, სტატუს-first, სიღრმე > სიგანე. საფრანგეთი = ვალიდაცია + reference implementation; აშშ სამედიცინო = `health` ვერტიკალი, არა მეორე პროდუქტი.
- **ბიზნეს-მოდელი (რეკომენდაცია):** ემიგრანტისთვის უფასო; შემოსავალი Helper Pro + პლატფორმის გრანტები → B2B2C pilot-ები. $9/თვე B2C paywall ბაზრის ევიდენსით არასიცოცხლისუნარიანია და დღესაც არაფერს იცავს (API საჯაროა).
- **ფაზები:** 0 ჰიგიენა+P0 (კვ. 1–2) → 1 ვალიდაცია+რეპოზიციონირება (კვ. 2–4) → 2 საფრანგეთის კონტენტ-მოდელი, ერთადერთი სქემის ცვლილება (კვ. 5–10) → 3 journey+retention (კვ. 11–16) → 4 მასშტაბი (თვე 5+, KPI gate).
